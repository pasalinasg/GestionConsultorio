# Sistema de interfaz inicial

- **Paleta:** tinta clínica `#042f2e`, marca `#0f766e`, fondo `#f8fafc`, superficie `#ffffff`, texto `#0f172a`, error `#be123c`.
- **Tipografía:** sistema sans; títulos semibold y compactos, texto normal de alta legibilidad.
- **Espaciado:** escala de 4 px; campos de 44 px de alto.
- **Patrón dominante:** cada flujo crítico se presenta con un panel contextual de propósito y un único formulario principal.
