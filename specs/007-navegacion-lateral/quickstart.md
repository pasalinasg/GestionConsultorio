# Quickstart: validar navegacion lateral

1. Ejecutar `npm run typecheck`.
2. Como propietario, validar Inicio, Agenda, Pacientes, Profesionales, Servicios y Usuarios y permisos.
3. Entrar a cada destino y verificar su resaltado activo.
4. Con un usuario que solo tenga `pacientes.visualizar`, confirmar que solo Inicio y Pacientes son visibles.
5. En movil, confirmar que la barra horizontal contiene las mismas opciones autorizadas.
