# PS_Platform context

PS_Platform is a modular SaaS framework for scalable business applications, built from reusable modules, shared UI components, and a consistent architecture.

Apply these principles:

- Prioritize maintainability over short-term speed.
- Reuse and compose before duplicating or creating new solutions.
- Keep business logic separate from UI.
- Follow the shared design system and maintain consistency across applications.
- Write clean, strongly typed, self-documenting code.
- Design features to be extensible, with convention preferred over configuration.
- Choose solutions that strengthen the platform as a whole, not only the immediate feature.

When trade-offs arise, state which principle drives the decision and keep the solution proportional to the feature's actual needs.
